# 🎵 Spotify Music Analytics Dashboard | Power BI

An interactive **Spotify Music Analytics Dashboard** developed using **Microsoft Power BI** to analyze music streaming performance, track trends, artist performance, and release-year patterns.

The dashboard uses a Spotify music dataset to transform raw data into interactive visualizations and business-style insights.

## 📊 Dashboard Preview

![Spotify Music Analytics Dashboard](dashboard.png)

## 🎯 Project Objective

The objective of this project is to analyze Spotify music data and create an interactive dashboard that helps understand:

* Most streamed tracks
* Top-performing artists
* Streaming trends by release year
* Track-level streaming performance
* Music and album performance
* Overall streaming patterns

## 📌 Key Dashboard Features

* **Total Streams KPI**
* **Total Tracks KPI**
* **Average Streams KPI**
* **Artist-level analysis**
* **Streams by release year**
* **Track and stream comparison**
* **Interactive artist filtering**
* **Song and album visualizations**
* Spotify-inspired **dark and green dashboard design**

## 📈 Analysis Performed

### Streaming Analysis

Analyzed the streaming performance of tracks and identified highly streamed songs.

### Artist Analysis

Compared artists based on their overall streaming performance and allowed interactive artist-level exploration.

### Release-Year Analysis

Analyzed how streaming performance varies across different release years.

### Track Analysis

Compared individual tracks using streaming metrics to identify high-performing songs.

## 🎨 Dashboard Design
